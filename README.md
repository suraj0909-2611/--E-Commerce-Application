# EcommerceApp

## Overview

EcommerceApp is a responsive e-commerce web application built using Angular. Users can browse products, search products, filter by category, view product details, add items to the cart, manage quantities, and submit inquiries through a contact form.

## Features

* Product Listing
* Search Products
* Category Filtering
* Product Details Popup (Angular Material Dialog)
* Add to Cart
* Cart Badge
* Quantity Increase / Decrease
* Remove Items from Cart
* Grand Total Calculation
* Contact Form with Validation
* Snackbar Notifications
* Local Storage Persistence
* Responsive Design for Mobile, Tablet, and Desktop

## Technologies Used

* Angular
* TypeScript
* Angular Material
* Bootstrap 5
* SCSS
* RxJS

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project:

```bash
cd EcommerceApp
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
ng serve
```

Open:

```text
http://localhost:4200
```

## Build

```bash
ng build
```

The build artifacts will be stored in the `dist/` directory.

## Assumptions

* Product data is loaded from a local JSON file.
* Cart data is stored in browser localStorage.
* No backend integration is required.
* The application is designed as a frontend assessment project.

## Implementation Notes

* Angular Standalone Components are used.
* Angular Material Dialog is used for Product Details.
* Angular Material Snackbar is used for notifications.
* Bootstrap Grid is used for responsive layouts.
* The application supports responsive design across mobile, tablet, and desktop devices.
